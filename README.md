# Gender Networks

This code generates co-authorship networks for focal authors.

When you use our code for your publications, please cite this repo.

## Data

Our bibliometric data are drawn from the Scopus database provided by Elsevier. Since data sharing is not permitted, a request must be submitted to Elsevier.

## Python codes for creating the networks 

The following Python notebooks are included:

- `create_network.ipynb` to create active and focal author networks
- `network_analysis.ipynb` to compute network measures of degree centrality, homophily, and interdisciplinary reach
